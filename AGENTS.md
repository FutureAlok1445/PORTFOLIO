# Portfolio working rules
Use src/data/content.js as the single editable content source. Resume facts must remain accurate; never invent clients, awards, testimonials, metrics, project links or dates. Document assumptions in DESIGN.md. Preserve the editorial systems direction, self-hosted fonts and accessible semantic content. Use React, Vite, React Router, GSAP and one Lenis instance. Clean up all effects. Honor reduced motion and touch input. Keep credentials without URLs visibly unlinked; hide TODO slots. Form submission must report success only after a successful service response. Run build and lint for each phase, commit completed phases, and verify responsive layouts and keyboard behavior. Do not publish without user authorization.
